# Hindu Festival Dates 2027 (computed)

Open dataset of 36 major Hindu festival dates for 2027, computed from real Sun and Moon positions (Swiss Ephemeris, Lahiri ayanamsa) by the team of [Dr. R.P. Sharma](https://drrpsharma.com/), Vedic astrologer since 1979.

Each row gives the observance date in India (IST), the classical rule used to fix it (tithi at sunrise, at midday, at sunset, at midnight, sankranti, and so on), and a link to a page with the full tithi window, muhurat and city timings.

## Files
- `festivals-2027.json` — slug, festival, date (YYYY-MM-DD, IST), rule, details URL
- `festivals-2027.csv` — the same data as CSV

- Dates are for India (IST). A tithi is a single instant, so the local date can differ abroad; use your own city's panchang. City-wise times are on each linked page and in the [daily panchang](https://drrpsharma.com/tools/panchang.html).
